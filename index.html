IRIS, FICO's design system

I started IRIS in 2020 with one or two teams using it. Today 50 domains across FICO's legacy and modern platforms depend on it, and marketing and product share one token language. I've built more than 90 components for it, in both the core design system library and the platform.

Falcon Fraud, rebuilt on IRIS

In 2023 we led the rewrite of Falcon Fraud and built it entirely from IRIS components. Dogfooding the system on a flagship product proved it could carry a full modern application.

Theming

Light and dark themes ship today, with light-alt and dark-alt built into the token library and ready to turn on. The switcher at the top of this page shows the idea.

Accessibility

We partnered with an accessibility consultancy on a WCAG AA audit and remediated every component. Building on the Angular CDK gave us full control over behavior and focus.

Beyond Angular

Semantic tokens and SCSS utilities for spacing, surfaces, typography, and icons let non-Angular teams match the IRIS look and feel.

Docs and quality

A documentation site with ephemeral StackBlitz examples, a Playwright test harness, semantic versioning, and release logs keep 50 domains confident in every update.

Tokens from Figma to production

We defined one token naming strategy across marketing and product, then automated the handoff. A theme change that used to need developer time now ships by running one GitHub Action.

AI that writes on-system UI

When AI writes UI, it should write your UI.

Over the last few years I've focused on making IRIS something AI tools can use correctly, not just something people can.

Requirements to working features
An agent skill that turns a product requirements document into a working Angular feature, with validated plans, IRIS generators, mock data, and scripted quality gates.
Token-based prototyping
A skill that builds framework-free HTML prototypes from IRIS tokens, so ideas look like the real product from the first draft.
Wireframes agents can read
A shared wireframe system with a fixed grid, a signature for each IRIS component, and full-page templates that other skills build on.
Figma MCP prototyping
Prototypes generated straight from design mocks, shortening the path from design to working UI.
Code review on every PR
An AI review agent runs when a pull request opens, keeping quality consistent across contributors.
Teaching the team
I mentor our junior engineers on best practices, code review, and working effectively with AI.
